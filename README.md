# 飞射射击 FEISHE STRIKE

打开即玩的俯视角波次生存射击。Canvas 2D 单文件，**零外部依赖**（无图片/模型/音频，全部程序化生成与实时合成音效），index.html 仅 38 KB。

## 玩法

- WASD 移动 + 鼠标瞄准射击，5 种武器随时切换（手枪/霰弹/步枪/狙击/火箭）
- 空格冲刺闪避（无敌帧），波间三选一强化（伤害/射速/移速/装甲/吸血/冷却）
- 每 5 波 Boss 战：熔核巨兽（径向弹幕）/ 电磁暴君（螺旋弹幕）/ 腐潮之王（扇形爆散），半血狂暴
- 4 类变异体兵种 + 死亡分裂机制，波次数值持续成长
- localStorage 最高分

## 操作

| 平台 | 操作 |
| --- | --- |
| 键鼠 | WASD 移动 · 鼠标瞄准 · 左键射击 · 1-5 换枪 · 空格冲刺 · P 暂停 |
| 手机 | 左摇杆移动 · 右摇杆瞄准自动开火 |

## 运行

```bash
python -m http.server 8031 --bind 127.0.0.1
# 打开 http://127.0.0.1:8031
```

单文件纯静态，任意托管直接部署。
