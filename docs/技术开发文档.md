## 1. 项目概述

### 1.1 产品定位

「飞射射击」是一款**打开即玩**的俯视角波次生存射击网页游戏。玩家在深空竞技场中面对一波强过一波的变异体，用 5 种枪械、冲刺闪避与波间强化生存下去，每 5 波迎接一场 Boss 战。

### 1.2 核心玩法

| 系统 | 说明 |
| --- | --- |
| 双摇杆射击 | WASD 移动 + 鼠标瞄准射击；手机端左摇杆移动 / 右摇杆瞄准自动开火 |
| 5 种武器 | 脉冲手枪 / 霰弹枪 / 突击步枪 / 狙击炮（穿透 3） / 火箭筒（范围爆炸），数字键切换 |
| 冲刺闪避 | 空格触发，0.16s 位移 + 0.5s 无敌帧，1.6s 冷却（环形冷却指示） |
| 波次制 | 每波敌人数量/血量/移速随波数成长；清波后 3.2s 休整 |
| 三选一强化 | 波间从 6 种强化池抽 3：伤害/射速/移速/生命上限/吸血弹头/冲刺冷却 |
| Boss 战 | 每 5 波一个 Boss（3 种轮换），血量过半进入二阶段加速弹幕 |
| 掉落 | 敌人 8% 概率掉血包（10 秒消失） |
| 最高分 | localStorage（key: `feishe-best`） |

### 1.3 计分

```
得分 = Σ敌人分值（10~18，幼体 5） + 波次奖励（波数×50） + Boss 击杀（300 + 波数×20）
```

| 竞品实现 | 借鉴 | 自研差异 |

## 3. 技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 渲染 | Canvas 2D 原生 API | 俯视角无需 3D，性能好、兼容性拉满 |
| 架构 | 单 HTML 文件（约 38 KB） | **零外部依赖、零构建**（比飞酷跑酷还少一个 three.min.js） |
| 音效 | Web Audio：`OscillatorNode + AudioBufferSource(白噪声) + BiquadFilter + DynamicsCompressor` | 枪声按武器差异合成（霰弹=噪声脉冲、狙击=扫频锯齿…） |
| 输入 | KeyboardEvent + MouseEvent + TouchEvent 双摇杆 | 桌面/移动一套代码 |
| 持久化 | localStorage | 无后端 |

## 4. 架构设计

```
index.html
├── CFG             配置中心（战场 2600×1900、玩家参数、波次节奏）
├── AudioSys        合成音效（tone 扫频 + noise 滤波噪声，经压缩器总线）
├── WEAPONS         武器表（伤害/射速/弹速/散布/弹丸数/穿透/爆炸半径）
├── ENEMY_TYPES     兵种表（行为参数+外观色+分值）
├── BOSSES          Boss 表（3 体轮换，弹幕 pattern 字段驱动）
├── S / P           全局状态 / 玩家状态（stats 承接强化叠加）
├── 波次系统        startWave（普通/Boss 分流）→ 清波 → endWave → showUpgrades
├── 敌人 AI         chaser 追踪摆动 / shooter 风筝射击 / dasher 蓄力冲锋 /
│                   splitter 死亡分裂 / 分离算法防堆叠
├── Boss AI         追击 + atkT 计时弹幕（radial/spiral/burst），半血二阶段
├── 战斗结算        hurtEnemy→killEnemy（分裂/掉落/吸血）/ hurtBoss（dying 防递归）
├── 特效            粒子池（上限 420）/ 伤害飘字 / 爆炸冲击环 / 屏幕震动 / 受击红闪
├── 输入            键鼠 + 双虚拟摇杆（触摸点自动分左右半屏，摇杆跟随按下位置）
└── Loop            update/render 分离，dt 封顶 50ms
```

### 4.1 实体与碰撞

- 全部圆形碰撞体，`dist2`（距离平方比较，避免开方）。
- 子弹命中：遍历敌人 + Boss，穿透弹减 `pierce` 计数，火箭弹在命中点或弹寿命尽头 `explode()`。
- 敌人间简单分离力防止堆叠成"一坨"。

### 4.2 弹幕三形态（Boss）

```
radial  环形 10~16 发（phase2 加密），旋转偏移 = boss.spin
spiral  3 条螺旋臂连续旋转发射
burst   朝玩家扇形 5 连发（±0.14 rad 间隔）
半血以下 atkT 从 2.4s 缩短到 1.5s
```

### 4.3 闪避冲刺的公平性设计

冲刺期间无敌帧 0.5s > 冲刺位移 0.16s，宽限窗口让玩家"穿弹幕"有从容感；冷却环绘制在角色脚环，信息不离手。

### 4.4 相机

跟随玩家（lerp 平滑），夹紧在战场范围内留 80px 余量；屏幕震动叠加在相机偏移上（`shake` 按武器后座/受击/爆炸分档）。

## 7. 开发踩坑记录

1. **Boss 击杀无限递归**：`hurtBoss` 击杀分支调用 `explode()`，`explode` 又对 Boss 范围伤害调用 `hurtBoss`——血量已 ≤0 仍重复进入击杀分支，栈溢出卡死。修复：`boss.dying` 标志位短路重入。教训：**"死亡触发 AoE"类逻辑必须防重入**。
2. **lerp 未定义**：全局只写了 `lerpN`，冲击环插值处笔误 `lerp`，运行时 172 连报。补 `const lerp = lerpN` 别名。
3. **测试脚本的波次偏移**：自动化验证 Boss 时先 `S.wave=5` 再 `startWave()`，而 startWave 内部先自增，实际生成第 6 波普通波。自动化脚本要吃透被测代码的调用语义。
4. **双摇杆触摸**：摇杆容器必须跟随首次触点移动位置（而不是固定在角落），否则拇指够不到。
